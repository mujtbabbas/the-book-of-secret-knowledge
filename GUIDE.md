# Reader's Guide — the-book-of-secret-knowledge

## What this project is

**The Book of Secret Knowledge** is a large, curated collection of the
material a working systems/security engineer actually reaches for —
*"inspiring lists, manuals, cheatsheets, blogs, hacks, one-liners, cli/web
tools, and more"* — gathered into one book-length README. Its motto sets the
tone: "Knowledge is powerful, be careful how you use it!" The audience named
in its **For whom?** section is the DevOps / SysOps / security crowd.

## How the content is organised

Everything lives in [`README.md`](README.md) (this guide was written from its
table of contents and the repository tree; the README is book-sized). After
the front sections — **What is it?**, **For whom?**, **Contributing**, **RSS
Feed & Updates**, **ToDo** — the **Table of Contents** leads into the
chapters:

- **Tooling:** CLI Tools · GUI Tools · Web Tools
- **Domains:** Systems/Services · Networks · Containers/Orchestration
- **Learning:** Manuals/Howtos/Tutorials · Inspiring Lists ·
  Blogs/Podcasts/Videos · Your daily knowledge and news · Other Cheat Sheets
- **Security:** Hacking/Penetration Testing
- **Shell craft:** Shell One-liners · Shell Tricks · Shell Functions

`static/` holds the book's images (including the cover preview the README
displays). `LICENSE.md` is MIT.

## How to use it

1. Use the **Table of Contents** — nobody reads this book cover to cover;
   jump to the chapter for the job in front of you.
2. Treat the shell chapters as a cookbook: copy a one-liner or function,
   understand it, then adapt it.
3. Follow the list/manual links out for depth; the book is the index, the
   linked resources are the library.
